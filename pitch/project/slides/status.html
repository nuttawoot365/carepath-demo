สถานะจริงของระบบวันนี้

ใช้งานได้จริงแล้ว

  • หน้าผู้ป่วยห้าภาษา พร้อมแผนที่ทีละชั้น
  • เวชระเบียน เปิด visit และพิมพ์บัตรคิว
  • จอจุดบริการที่ผูกกับมือถือผู้ป่วยจริง
  • โต๊ะช่วยเหลือ และการแจ้งเส้นทางชำรุด
  • ผังเส้นทางและผลกระทบเมื่อปิดเส้นทาง
  • โครงสร้างฐานข้อมูล 17 ตาราง และอัลกอริทึม

ยังเป็นแบบหน้าจอ

  • นำเข้าผังจากไฟล์ CSV
  • ภาพรวมผู้บริหารและจุดคอขวด
  • จอเรียกคิวหน้าห้องตรวจ

ยังไม่ได้ทำ

  • ผู้ใช้และสิทธิ์ · บันทึกการใช้งาน
  • REST API ที่ต่อฐานข้อมูลจริง

ทุกเมนูในระบบติดป้ายไว้ตามความจริง กดแล้วไม่เงียบ

บอกสถานะตรง ๆ ดีกว่าให้กรรมการกดเจอเอง · ถ้าถามว่าทำไมยังไม่มี API ตอบเรื่องข้อจำกัดของ Cloudflare Workers สามข้อที่บันทึกไว้ใน README
