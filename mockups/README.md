## หลักการที่ใช้ตัดสินใจ

1. **สัญลักษณ์มาก่อนภาษา** — ลูกศร ไอคอน ตัวเลข เป็นแกน ข้อความเป็นส่วนเสริม
2. **ไม่เกิน 2 แตะ** จากสแกน QR ถึง "ไปไหนต่อ และไปยังไง"
3. **ไม่บังคับใช้มือถือ** — ทุกอย่างพิมพ์ลงบัตรกระดาษได้
4. **ความต้องการพิเศษตั้งครั้งเดียว** ที่เวชระเบียน แล้วมีผลทั้งวัน
5. **เจ้าหน้าที่กดปุ่มเดียว** — ถ้าเพิ่มภาระ เจ้าหน้าที่จะไม่กด แล้วระบบก็ตาย
6. **ไม่มีข้อมูลอ่อนไหวบนจอ** — จอสาธารณะแสดงเลขคิวอย่างเดียว
