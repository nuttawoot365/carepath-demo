### Sprint 4 — Backend & Database (ทำแล้ว)

ยกเครื่อง API จาก Express 5 เป็น **NestJS 11 + TypeScript** โดยไม่แตะฐานข้อมูล

- controller 7 ตัวแทนไฟล์ route เดิม — `auth · map · catalog · visits · patient · stations · admin`
- `AuthGuard` + `@Roles()` แทน `requireRole()` — ตรวจสิทธิ์ที่ API ไม่ใช่ที่หน้าจอ
- `DbService` ครอบ `pg.Pool` ด้วย `query()` และ `withTransaction()` — **SQL และ schema.sql เดิมไม่เปลี่ยน**
- ตรรกะโดเมน (Dijkstra ตามความต้องการพิเศษ · topological sort · ประโยคนำทาง) ย้ายเป็นฟังก์ชันล้วน ทดสอบได้โดยไม่ต้องมีฐานข้อมูล
- เทสต์ย้ายจาก `node:test` เป็น jest — **24 เคสผ่านทั้งหมด**

### Sprint 5 — Frontend & Integration (ทำแล้ว)

ยกหน้าเว็บจาก HTML นิ่งหลัง nginx เป็น **Next.js 15 App Router + TypeScript**

- 4 หน้าที่ต่อ API จริงเขียนใหม่เป็น React — `/login` `/registrar` `/station` `/patient`
- โทเคนการออกแบบที่เคยคัดลอกซ้ำในหัวไฟล์ HTML ทุกใบ รวมเหลือ `app/globals.css` ที่เดียว
- อีก 7 หน้ายังเป็น HTML นิ่งใน `public/` ที่ `app/build.mjs` สร้างจาก `data/` เหมือนเดิม
- **ลิงก์เดิมไม่พัง** — `/patient-mobile.html?t=` redirect ไป `/patient?t=` บัตรคิวที่พิมพ์ไปแล้วยังสแกนได้

ทดสอบกับฐานข้อมูลจริงแล้ว: login ครบ 5 บัญชี · RBAC คืน 403 · กฎลำดับสถานะคืน 409 ·
Dijkstra คิดเส้นทางรถเข็น 147 เมตร 9 คำสั่ง · แทรกขั้นเอกซเรย์เข้าลำดับที่ 6 ถูกตำแหน่ง ·
กด "เสร็จ" ที่จอจุดบริการแล้วหน้าผู้ป่วยเปลี่ยนตาม

## ลำดับการสาธิต 7 นาที

1. **ปัญหา** — ผู้ป่วยยืนงงกลางโถง ไม่รู้ว่าต้องไปไหนต่อ (30 วิ)
2. **เวชระเบียน** — เปิด visit จริง ติ๊กรถเข็น + ผู้สูงอายุ → ได้บัตรคิวพร้อม QR (1.5 นาที)
3. **สแกน QR ด้วยมือถือจริง** → หน้าผู้ป่วยขึ้นเส้นทางทีละขั้น (1.5 นาที)
4. **จอจุดบริการ** — กด "เสร็จ" → **หน้ามือถือเปลี่ยนเองใน 5 วินาที** (1 นาที · จุดพีคของ demo)
5. **ปิดลิฟต์ B** → ระบบคิดเส้นทางใหม่ให้ผู้ป่วยรถเข็นทันที (1 นาที)
6. **แพทย์สั่งเอกซเรย์เพิ่ม** → ขั้นใหม่แทรกก่อนชำระเงินอัตโนมัติ (1 นาที)
7. **ปิดท้าย** — ผังจริงนำเข้าผ่าน CSV ได้โดยไม่ต้องแก้โค้ด (30 วิ)

### คำถามที่กรรมการน่าจะถาม

| คำถาม | คำตอบสั้น |

## คำสั่งที่ต้องใช้วันนี้

```bash
cd ~/Documents/Hackathon/carepath-v2

docker compose up -d --build          # ยกทั้ง stack
docker compose exec api npm run reset # ล้างและนำเข้าข้อมูลใหม่

open http://localhost:5173/login

cd backend && npx jest                # 24 เทสต์
```
