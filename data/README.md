# data/ — ข้อมูลนำเข้า (สมมุติทั้งหมด ไม่มีข้อมูลบุคคลจริง)

| ไฟล์ | เนื้อหา |
|---|---|
| `nodes.csv` | 48 จุดในโรงพยาบาล · อาคาร A (ชั้น 1–2) · B (1–3) · C (2–4) |
| `edges.csv` | 52 คู่ทางเดิน · `bidirectional=1` สร้าง 2 แถว · `walk_seconds` ว่าง = `distance_m ÷ 1 m/s` |
| `departments.csv` | แผนก · สีป้าย · จุดยื่นบัตร (ขอบเขตของผู้ใช้ role `station`) |
| `pathways.csv` | แม่แบบขั้นตอน DM-FU (เบาหวาน 7 ขั้น) และ WALKIN (5 ขั้น) · `prereq_steps` คั่นด้วย `;` |
| `users.csv` | เจ้าหน้าที่ 6 คน · รหัสผ่านเดโม `demo1234` (แฮชด้วย bcrypt ตอน import) |
| `patients.csv` | ผู้ป่วยสมมุติ 10 คน |
| `node-photos.csv` | รูปจริงของแต่ละจุด (`node,url,caption_th,caption_en`) — เริ่มต้นว่าง เติมเมื่อออกไปถ่ายสถานที่จริง |
