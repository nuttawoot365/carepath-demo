# prototype/ — ต้นแบบที่กดได้จริง

`patient-mobile.html` คือหน้าผู้ป่วยที่ใช้ทดสอบบนมือถือจริง ไม่ใช่ภาพนิ่ง — ไฟล์เดียวจบ ไม่มี build ไม่เรียก API
ข้อมูลขั้นตอนและเส้นทางในไฟล์นี้ตรงกับ `data/pathways.csv` และ `data/edges.csv` ของโครงการ

## เปิดดู

```bash
./serve.sh prototype 5174
```

สคริปต์จะพิมพ์ที่อยู่สองอัน — ของเครื่องนี้ และของมือถือ (เช่น `http://192.168.1.54:5174/patient-mobile.html`)
พิมพ์อันหลังลงเบราว์เซอร์มือถือที่ต่อไวไฟวงเดียวกันได้เลย ครั้งแรก macOS อาจถามว่าจะอนุญาตให้ python รับการเชื่อมต่อไหม ให้กดอนุญาต
ถ้าไม่อยากให้เครื่องอื่นเห็น ใช้ `HOST=127.0.0.1 ./serve.sh prototype 5174`

## สิ่งที่กดได้

| ส่วน | พฤติกรรม |
|---|---|
| ปุ่ม **ดูเส้นทาง** | สลับไปหน้าคำสั่งนำทางของขั้นถัดไป คำนวณจากตำแหน่งปัจจุบัน |
| **ทีละข้อ / ดูทั้งหมด** | สลับระหว่างอ่านทั้งเส้นทาง กับดูทีละคำสั่งบนจอเดียว |
| **🔊** | อ่านคำสั่งออกเสียงตามภาษาที่เลือก (`speechSynthesis`) |
| **📍 ฉันอยู่ที่…** | เลือกจุดสังเกตใกล้ตัว แล้วระบบคิดเส้นทางใหม่จากจุดนั้น |
| **ก+** | โหมดตัวใหญ่ 135 % และเปลี่ยนเป็นทีละคำสั่งอัตโนมัติ · จำค่าไว้ในเครื่อง |
| **EN / ไทย** | สลับภาษาทั้งหน้า รวมคำสั่งนำทางและข้อความเตือน |
| **🎬 เดโม** | จำลองเหตุการณ์ที่ปกติมาจากเจ้าหน้าที่: กดเสร็จ · ปิดลิฟต์ B · สั่งเอกซเรย์เพิ่ม · เริ่มใหม่ |

สั่นเตือน (`navigator.vibrate`) ทำงานบน Android · บน iOS จะเงียบแต่ไม่พัง

## ขอบเขต

เป็นต้นแบบหน้าจอเท่านั้น — สถานะเก็บอยู่ในหน่วยความจำของเบราว์เซอร์ ไม่ได้ต่อฐานข้อมูล
เมื่อ REST API เสร็จ หน้าจริงใน `frontend/public/` จะใช้หน้าตาชุดนี้แต่ดึงข้อมูลจาก `/api` แทน
